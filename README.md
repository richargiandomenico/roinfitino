# ROI Vision Pro

olá, responda e planeje tudo sempre em portugues ok. Vamos colocar um banco de dados para um sistema de analise de roi e utm para um projeto de adsense/adx. Melhores algumas coisas, como puxar o dólar real do dia e tbm opção de editar caso e queira trabalhar com um dólar diferente, pode ser um menu de configurações onde podemos por o dólar, taxas do meta, imposto etc para poder calcular o roi.

Histórico de simulações - aqui vai ficar os registros conforme eu for colocando manualmente, tbm coloque a opção de excluir um registro, pq vou colocando ao longo do dia, mas depois vou excluindo só para ver a evolução ou não da URL... tbm criei uma forma de por "projetos" ou seja, cada URL/nicho será um projeto a ser trabalhado.

🧭 Análise de Tráfego do Funil (Visitas → P2/P3) - aqui tbm vamos analisar como está o desempenho e conversão das páginas indo da P1, p2, etc. Tbm vamos ter os registros e opção de excluir.

Em cada linha tbm coloque a analise ou seja, qual o cpa ideal para ter roi, mude a cor das linhas conforme for ficando positivo ou negativo.
